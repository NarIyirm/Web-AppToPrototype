# WebAppToFigma 移动端界面约定

更新：2026-10-21。用户要求移动 App 更简约、精致，并贴近日常操作习惯。上一轮采集/拆层本地验证已获用户确认；本轮 UI 仍需 Expo Go 验收。

## 使用场景

在手机快速导入截图、采集网页或整理 App 页面，预览后发往电脑继续转换。保留“添加画面 / 我的项目 / 发送到电脑”三个标签，不要求用户理解底层采集或传输技术。

## 视觉基础

- 沿用移动端蓝色品牌，与既有图标一致；颜色集中在 `src/ui/tokens.ts`，随设备切换浅色/深色。
- 系统字体、系统符号；页面标题 30，详情标题 26，正文 15–16，辅助文字 12–14。文字允许跟随系统缩放，长名称换行。
- 20 点页面留白、12–24 点内容间距、680 点最大正文宽度；白色或深色平面分组，避免装饰性阴影、渐变和多层卡片。
- 主按钮蓝底白字，次按钮浅蓝底，辅助操作用文字按钮。主要触控区域至少 44 点；返回在左上角。

## 操作结构

- 添加画面：先显示保存项目，再列出截图、App、网页三个入口，每项说明用途；最近画面可直接打开。
- 项目：列表显示封面、名称、画面数、时间；详情用紧凑的缩略图列表。选中用圆形勾选标记和色彩共同表示，最多选择 5 个。
- 连接：未连接时解释电脑配对码的位置；连接后显示设备名称和状态，底部固定发送、进度与暂停操作。
- 预览：大图优先，名称、裁切/旋转、文字校对按需展开；底部固定发送，不必滚到底找按钮。
- App 采集：三段进度提示；Expo Go 的能力边界直接说明。真正的 iOS 系统采集控件保留 64 点原生区域，不能用 JS 图标冒充原生按钮。
- 详细帮助、文件导出、删除保持次级入口；删除仍二次确认。错误保留具体内容，不能用装饰状态代替真实结果。

## 安全区与验证

继续使用 Screen / SafeAreaSurface 和独立的 SafeAreaModal。固定底栏位于同一安全区内部，不手写刘海/手势条尺寸，不重复计算 tab bar inset。裁切弹窗保留独立滚动隔离、确认/取消行为。

代码验收：lint、类型检查、既有业务测试；实际页面用本地受控数据验证主要交互、小屏/横屏、深色模式和底部操作。真实手机的键盘、系统大字体、原生图标与采集授权仍由设备验收确认。未获本轮用户确认前不触发原生安装包、云构建、提交或推送。
