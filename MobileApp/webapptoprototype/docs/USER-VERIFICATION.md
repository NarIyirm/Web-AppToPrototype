反馈时主要告诉我：入口/指引是否清楚、示例页面是否能点击、框选是否顺手、发送与电脑转换结果是否符合预期。这批不需要提交 TestFlight 或提供 Apple 配置。Expo Go 无法验证真正的跨 App 系统采集能力。

## 1. 最短链路：截图→电脑→Figma

1. 手机“我的项目”新建“手机验证”，从“添加画面”选择该项目并导入一张自有截图。确认取消选择不会增加空画面。
2. 画面中改名称并保存；裁切/旋转会另存一个状态。返回后确认原状态和新状态都在，顺序能上移/下移。退出重开App应保留。
3. 用自建合成图测试遮挡。可使用本目录`verification/synthetic-capture.png`（640×960）；填写X=32、Y=350、宽=576、高=110并点击“将此范围遮挡为黑色”。重开画面仍应黑色。遮挡会清空旧OCR/网页观察，已经导出的旧文件需要重新导出。
4. 点击“在本机识别文字”，观察中英文文字/位置；修改一条文字，点击“保存文字校对”。Android置信度显示未知是设计行为，不应伪造数字。无模块/识别错误请保留原错误信息。
5. 回项目勾选1–5个画面，导出素材包。将`.w2pm.zip`交给电脑，在“转换结果”点“打开手机素材 / 转换包”。应得到源画面对照、转换图层和近似/图片告警。
6. 简单纯色背景文字只有通过检查并真正清除原字后才成为可编辑TEXT；复杂背景或相互重叠区域应保留图片。手机OCR成功不等于所有文字都可编辑。
7. 发送到Figma。编辑一个已输出的TEXT，再移动/隐藏它，检查下面没有原文字像素；参考图不应额外覆盖设计根。遮挡区域不得在导出画面或文字里重新出现。

预期：项目数据稳定，遮挡写入真实像素；电脑能区分手机素材与最终设计包；图片/近似/可编辑部分有告警；真实Figma编辑可用。

## 2. 网页采集

1. “采集”输入自己允许测试的HTTPS网页，含中文、英文、按钮和图片。打开后先浏览/滚动，再保存当前视口。
2. 返回网页，切“选元素”，触摸一个标题/按钮，保存范围；再试“画矩形”双向拖动。输出大小和实际范围应一致，没有蓝色选框残留。
3. 导航、旋转、键盘或页面内容变化后，应清空旧选择/拒绝旧任务，不把旧DOM配到新截图。网页缩放后先恢复缩放再采集。
4. 导出到电脑，校对基础文字/背景/图片区域。当前只实现基础DOM子集，复杂CSS/层叠可能近似；手机长页、多选/排除/父级还未实现，不计这些验收通过。

反馈时附原网页地址（移除敏感查询/凭据）、手机选区截图、电脑结果、哪个边界错及大概误差。

## 3. 两端系统采集（分别执行）

**Android：**“采集→系统采集”，点击“授权并开始采集”，在系统选择允许共享的测试App/屏幕。切到该App等待约6–10秒，从通知或系统共享入口停止，回本App刷新。应出现待整理帧，点预览，再保存到项目并OCR。拒绝授权应安全返回；再次采集需新的系统授权。检查系统停止、锁屏后采集确实结束。

**iOS：**“系统采集”点击系统录屏按钮，选择“界面采集”并开始广播，切到测试App等待约6–10秒，从控制中心或系统录屏状态停止。返回本App刷新，预览并保存帧。扩展和主App都需要正确签名/App Group。入口缺失、广播立即退出或没有帧时，反馈实际iOS与构建/签名错误。

两端均每3秒最多保存一帧，最多20帧或60秒；音频不保留。待整理帧可逐帧丢弃。受保护画面可能为空白，不绕过保护。验证横竖屏、系统停止后没有继续积累帧。

## 4. 扫码直传

1. 手机/电脑同一局域网。电脑右侧顶部“手机”→“生成手机配对码”。多网卡时选手机能访问的网络地址。Expo Go和包含传输模块的独立包均可扫码，分别走加密LAN/固定证书TLS。
2. 手机“发送到电脑”扫码，或展开粘贴电脑“复制配对信息”的内容。核对电脑名后点“连接”，在电脑弹窗允许这台手机。码2分钟内有效且单次使用，会话15分钟。
3. 手机选择项目和1–5个画面发送。手机成功提示应只说电脑已收到；此时不能说Figma已导入。
4. 电脑“手机素材”页签自动刷新，点击“转换并打开”，校对后发送Figma。收到、转换、实际导入分开判断。
5. 传输中暂停或临时断开Wi-Fi，恢复后点“重试发送”。应查询电脑已确认位置继续，不重复生成成功收件。
6. 关闭手机接收应断开会话。电脑重启后要新配对，已完整收到的文件仍可打开。当前跨手机进程/电脑重启的部分上传不承诺续传，需重新发送。
7. 可选错误检查：在未使用的配对信息中改一位certificateSha256，连接必须失败；过期或已用码也应被拒绝。失败不应影响已有项目/收件。若网络不通，继续用文件导出路径并报告网络/防火墙提示。

分别记录Android→Windows、Android→Mac、iPhone→Windows、iPhone→Mac，不能用一个组合代替全部。

## 5. 多状态手工原型

电脑在“转换结果”点击“加入原型项目”，准备列表/详情/弹窗画面。在“项目原型”页签命名排序，选已有元素或绘制热点，设置跳转/打开弹窗/关闭弹窗，生成项目后发送Figma。真实播放应按你的手工连线执行，不自动猜测原App业务动作。
