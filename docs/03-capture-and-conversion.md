# 03 采集与转换细则

版本：v1.9｜状态：m2.4及此前用户确认保留；m2.5文字、m2.6层叠、m2.7 SVG、m2.8表单/生成内容及m2.9常见外阴影第一批已开发，最终Figma待用户。公网HTTPS已补实际样例检查，实际状态见PROGRESS。

## 1. 单次采集流水线

`浏览就绪 → 选择 → 预检 → 页面稳定等待 → 布局读取 → 资源固化 → 场景归一化 → 转换 → 数据包校验 → 预览/保存`。

每一步记录 captureId、阶段、耗时、告警和失败原因。原始读取与转换分开，允许同一份可用快照用新版转换器重新处理。跨页面跳转、框选对象失效、页面崩溃导致本次采集中止，不继续拼接错误场景。

采集先从 DOM + getComputedStyle + Range 几何信息实现；CDP DOMSnapshot/绘制快照只是后续补充，不假设某个接口自动提供可还原的全部 CSS 和资源。

## 2. 选择模型

SelectionSpec 包含：mode、页面实例 pageEpoch、viewport、scrollOffset、选中源节点、排除源节点、可选矩形、边界策略和内容范围。

页面导航后 pageEpoch 必须变化；原来选择不能套用到新页面。异步 DOM 更新时，用捕获会话内的节点句柄优先定位，selector 仅供诊断或最佳努力重定位。目标不存在则显示“页面已变化，请重新选择”。

### 2.1 元素与 Section 点选

1. 根据指针位置读取命中的元素层级，排除工具自身 ShadowRoot、无尺寸节点和明确不可见对象。
2. 候选优先级：用户上次锁定层级 → semantic section/article/main/nav/dialog → 有背景/边框或布局容器 → 实际命中元素。标签只是线索，不是唯一判据。
3. 展示当前候选边界和名称；滚轮或“扩大/缩小”按钮调整层级，不把正常页面滚动与层级选择混用。
4. 点选后保留该子树及必要的裁剪、祖先透明度、背景、变换和层叠上下文。不能只取 innerHTML 重新排版。
5. 默认背景为目标区域实际背景；透明区域保留透明还是补页面底色由导出设置明确选择。

### 2.2 严格矩形

1. 将鼠标位置从宿主视图坐标转换成页面视口 CSS 像素，再转换到文档坐标。
2. 先找与选区相交的可见绘制贡献，包括文字片段、背景、阴影和子元素；父容器不相交时仍考虑溢出的子元素。
3. 保留必要祖先信息以还原裁剪、透明度和绘制顺序；先构造归一化场景，再裁剪显示，不能简单移动所有命中节点至顶层。
4. 输出根 Frame 尺寸等于选区，内部节点相对选区偏移，外层 clipsContent=true。
5. 被切断的文字仍保留完整文本节点，通过外层裁剪显示；不能静默删除文字后半段。报告说明存在选区裁剪。
6. 背景与复杂叠层不能拆解时，只对最小无法还原区域保留图片，并标为 rasterized。

v1 支持轴对齐矩形；旋转、圆形和自由路径选区暂不支持。

### 2.3 元素吸附矩形

m2.1 当前规则：对与原框相交的按钮、链接、图片、文字块、简单行容器及叶子元素做一次向外扩展；不把 html/body/main 当作吸附候选，不沿扩展结果继续选择邻居。祖先 overflow 的固有裁切仍保留。实际边界与原框大小显示在源预览说明，保存前由用户确认。若扩展超过四个视口宽/高，拒绝并要求缩小或改选 Section。

早期草案建议的“相交 50% 或中心点”启发式暂未采用；后续可根据真实站点反馈调整。当前完整元素不是任意业务组件的语义识别，不自动把复杂卡片全体都当作一个元素。

### 2.4 多选、重叠和排除

当前 m2.2 子集：最多 20 个元素/Section 根、100 项排除，同父子只保留父级；点击与转换前均去重。捕获保留实时 Element 句柄，节点失效整批拒绝，用户可移除失效项后重试；不静默跳过。独立模式用多个 screens，合并模式用透明共同根与原始相对坐标，仅绘制所选根及其后代。排除在遍历时跳过子树、不过滤父级背景，也不改源 DOM。图片按整批摘要去重，预算沿用，超过即拒绝。启用矩形会替换元素列表，当前视口不应用列表排除。下列完整规划中“多矩形、让父子都独立导出”等未实施，不能描述为现有功能。UI/验收见 docs/12。

- 同时选中父级和后代时，默认只保留父级，后代不重复生成；用户可改成独立 Frame。
- 不相邻选择默认各成一个 Frame，记录源页面原始位置；合并模式建立共同选区根。
- 矩形重叠默认保留为两次独立捕获，不在无提示情况下合并。
- 排除默认剔除节点绘制贡献、保留空间；不修改源 DOM 或让后续元素重新排版。
- 若排除区域已经并入同一张图片，不能声称精确删除；先尝试重新分解，失败则报告不支持该排除操作。
- 每个选择有独立 captureId，可统一分组导出。缺失选区不影响其他已保存捕获。

## 3. 坐标与尺寸

协议场景中的长度全部使用 CSS px，Figma 映射采用 1 CSS px → 1 Figma 单位。DPR 只影响位图清晰度，不乘到图层位置与尺寸上。Electron 页面缩放、宿主系统缩放、DPR 分别保存；M0 必须验证三者的坐标换算，不能用一个倍率近似。

- getBoundingClientRect 得到视口中的轴对齐边界；无复杂变换时，documentX=rect.left+scrollX，documentY=rect.top+scrollY。
- 子节点位置相对其实际输出父节点，父节点重组后重新换算，不直接照抄 DOM offsetLeft。
- 旋转/缩放节点需要保存局部变换；只有边界框不足以恢复旋转。简单二维变换受控支持，3D/透视先图片保留。
- overflow、滚动容器、border/padding 的坐标系单独处理。嵌套滚动先记录当前视图；不假设所有容器都已展开。
- fixed/sticky 元素的视口状态与文档流不同。视口捕获保留所见；整页只保留一份，并标记采用的锚定状态。
- 导入画布位置与源页面坐标分开：源根从 (0,0) 起，导入时才为不同 Frame 排列间距。

## 4. 页面稳定与动态内容

等待顺序：DOM 可读取、字体等待、已参与选区布局的图片 decode、短期布局稳定。默认字体/资源等待上限 5 秒、稳定窗口 300 毫秒、单次准备上限 10 秒；这些是起始配置，M0/基准测试后调整。

持续轮询页面可能永远没有 network idle，因此不能把网络完全空闲当作唯一完成条件。超时后允许“按当前状态采集”，报告 unresolvedResources/layoutUnstable。

采集器先读布局再计算，批量处理，避免边读边改导致频繁重排。默认不强制修改网页隐藏状态、不点击业务按钮、不提交表单。必要的动画暂停只作用于采集期间，记录原状态并在结束/取消时恢复；不把“暂停到哪一帧”描述成全部动画还原。

选择工具和高亮层在最终截图、提取前临时隐藏，在 finally 中恢复。滚动、窗口大小、焦点等可恢复状态也在结束时归还。因页面导航无法恢复时要说明。

m2.1：源截图隐藏工具叠层后使用目标 WebContents 的真实位图，按截图实际尺寸/捕获 CSS 视口尺寸换算，不写死 DPR。视口采集排除原生滚动条；captureContext 保存浏览器视口与缩放元信息。预览只覆盖当时可见部分、长边最多 2048px，部分范围超出视口会提示；不自动滚动拼接。预览与节点包分开保存，缺失不阻断主 JSON 导入，不能把源截图当作转换保真已验收的证据。

## 5. 有界整页与懒加载

以下为 m2.3 当前实现，覆盖第 4 节 m2.1 单视口预览的历史限制。操作与用户验收见 [docs/13](13-full-page-and-long-demo-acceptance.md)。

“整个页面”输出当前宽度下一个原生长 Frame，selection.mode=full_page、contentScope=loaded_content，忽略区块根/排除但保留原选择列表。滚动加载默认开启，可关闭，仅转换当时已加载文档。两种方式都临时回顶部，统一读取 fixed/sticky 的一次静态状态；captureContext.scroll 为快照的 (0,0)，不是用户开始时位置。

最多 30,000 CSS px、30 次准备滚动、30 秒准备；整轮 90 秒等待预算，单次页面读取/截帧有 15 秒保护。每步约 0.8 视口，100ms 取样直到三次稳定或 900ms；真实绘制后再等待一次，让懒加载先触发。准备上限在步骤之间检查，不是强杀网页请求。限制触发只保留已访问的高度，返回 W_FULL_PAGE_PARTIAL。DOM 提取仍限 3000 元素/5000 图层/60000 字符/8 秒，不随长页放宽。

准备后回顶部读取一次 DOM，再按位置生成源参考；fixed/sticky 不因滚动次数复制，I_FULL_PAGE_POSITION 明确静态近似。用文档高度、内容变更版本及快照几何检测采集期间变化，引用截图不能和不同布局的包静默混用。I_FULL_PAGE_CAPTURE 记录准备开关、步数、文档/采集高度、partial/reason/settled 及参考数量/方式。

输入暂锁、叠层隐藏、背景计时节流暂关闭；finally 恢复原滚动位置和工具状态。取消保留旧成功包；跨文档/同文档导航中止，避免旧坐标污染新页面，拒绝悬空异步读取。网页已追加 DOM 与请求不回滚。页面原滚动位置不能精确恢复时 W_SCROLL_RESTORE；不稳定时 W_PAGE_UNSTABLE。

记录可见 li/article/role=row/data-index 项的节点/文字，发现回收或替换时 E_FULL_PAGE_VIRTUALIZED 保守拒绝。它是启发式，不覆盖所有框架；内层独立滚动容器不自动展开。无限页在预算内返回部分内容，不宣称加载所有记录。

源参考最多 12 段/32 MiB，单段长边 2048px。能覆盖时连续取图（末段可重叠），否则均匀抽样首尾并标注 sampled，不生成去重接缝的拼接长图。真实参考里的 fixed/sticky 可以重复，原生节点仍一次。附件不进 assets、不作为整页位图导入；保存/重开协议见 docs/04。原生图层保持 CSS 尺寸，包内 PNG/JPEG 4096px 等现有资源预算不变。

## 6. 元素兼容与降级矩阵

m2.4 已实现以下表中 img 的五种 object-fit/常见 object-position、单图背景 cover/contain/尺寸/定位，以及常见线性渐变子集。图片完整资源对应实际显示 rect，独立 Frame 按内容/背景裁切，保留普通圆角、边框和文字；渐变输出原生可编辑填充，不烘焙为截图。边框/内边距按 border/padding/content-box 换算，背景先于内容；资源固化后按实际解码尺寸计算背景几何。默认 repeat 仅当一张图已经覆盖重复轴时无需额外平铺，否则省略并告警。复杂背景/渐变、越界色标和广色域插值不静默近似。精确支持范围、告警及新增 E01–E07 见 [docs/14](14-visual-fidelity-acceptance.md)；协议扩展见 docs/04，表中其他“完整桌面验证版”内容仍是后续目标。

| 内容 | 第一条链路 | 完整桌面验证版 | 明确降级 |
|---|---|---|---|
| 纯色、透明度 | 原生 fills | 保留祖先合成影响 | 混合模式复杂时局部图片 |
| border、圆角 | 常规单色边框 | 单边、不同圆角需验证映射 | 不支持的虚线/多层边框报告 |
| 阴影 | 暂可报告忽略 | 常见 drop shadow 映射 | inset/滤镜复杂时图片 |
| 渐变 | 单色替代须报告 | linear-gradient；radial 单独测 | conic、复杂组合先图片 |
| 普通文字 | 原生 TextNode | 富文本 runs、换行和中英文混排 | 缺字体时替代并报告 |
| img | 固化当前 currentSrc | object-fit、object-position 裁切 | 无法读取则保留区域截图 |
| background-image | 暂限单图 | cover/contain 与平铺分开支持 | 多背景合成必要时图片 |
| SVG | 简单路径转矢量 | 内联样式、尺寸与 viewBox | filter、foreignObject 复杂时图片 |
| 表单 | 当前可见外观 | checked/disabled/placeholder | 不运行真实输入和校验逻辑 |
| canvas/WebGL | 图片区域 | 保持图片并可替换 | 不声称内部图形可编辑 |
| video/GIF | 当前帧/海报 | 维持静态状态说明 | 不迁移视频播放行为 |
| iframe | 首版告警/区域图片 | 同源内容单独适配 | 跨域/不可访问帧明确降级 |
| Shadow DOM | 开放根可遍历 | 插槽/继承样式专项测试 | closed root 先图片 |
| Grid | 绝对坐标 | 保留原生图层位置 | 不强制转 Auto Layout |
| Flex | 绝对坐标 | 简单单轴 Flex 可选 Auto Layout | 换行/重叠复杂时保留绝对布局 |
| 伪元素 | 首版告警 | before/after 常见文字/形状 | 复杂绘制局部图片 |
| mask/clip-path/3D | 局部图片 | 简单矩形裁剪原生 | 不支持几何需报告 |

所有 fallback 必须包含原因、源节点 ID、影响属性、保留方式和可编辑性等级。资源丢失用 missing，不能算作正常 rasterized。

## 7. 文字还原

m2.5 当前子集覆盖下述完整目标中的：完整字素Range读取、同视觉行安全合并富文本、颜色/字体/字距/单一装饰线、常见upper/lowercase与CSS字体列表替代诊断。它仍按渲染行保存，不宣称完整原生段落重排。跨有背景/透明度/定位/裁切影响的行内元素不合并；混合字号保留独立原生片段并报告W_TEXT_FRAGMENTED。居中/靠右用实际行坐标保留，Text自身保持左对齐行片段。特殊布局/装饰明确告警。完整支持边界、TXT01–TXT07与缺字诊断限制见[docs/15](15-text-fidelity-acceptance.md)。以下“完整语义段落优先”等仍是后续目标，不等同当前已实现。

遍历文本节点而非对每个元素调用 innerText 生成一份文字，避免祖先与后代重复。用 Range 获取文字片段和行几何，处理内联样式 runs、空格折叠、white-space、text-transform、line-height、字距、对齐和截断。

默认策略：完整语义段落优先一个 TextNode，富文本使用范围样式；连续行如果无法在 Figma 中复现换行，再按行拆分并告警。逐字拆成图层只用于诊断，不作为默认输出。

字体顺序：源 family+style/weight → 可用同族替代 → 配置的中文/拉丁 fallback。插件先加载所需字体，再设置文字及样式。网页字体存在不意味着 Figma 能直接使用；下载字体不等于已安装，不能默认自动安装系统字体。缺字和字体替换分别报告。

文本溢出策略由源布局与截断状态确定，不通过任意缩小字号掩盖换行偏差。文字编辑能力和视觉接近分别计分。m2.8读取显示区域在采集范围内的控件当前值/选中标签；password仅输出显示圆点，不读取到测量节点或导出其值。hidden inputs和范围之外的控件不进入包；可见textarea的完整值行保留在原生显示裁切下，按当前滚动位置呈现，不把每个被裁切行当作无关DOM删掉。

m2.8文字测量在工具闭合Shadow DOM的隐藏镜像中完成，使用计算样式及Range，不改源表单value/checked/DOM。控件主题、特殊文字布局和复杂类型明确近似/告警。before/after仅先实现可靠绝对定位的基础生成框/文字，参与现有层叠/有效裁切链；文流和复杂效果不猜测。详见[docs/18](18-forms-and-generated-content-acceptance.md)。

## 8. 资源固化

优先捕获当前已解码/已加载资源；再由与目标会话关联的受控资源服务获取需要的图片字节。记录 currentSrc、MIME、实际尺寸、哈希和捕获内引用。凭据只用于原站会话请求，不写入导出包，不随重定向泄露给其他来源。

blob URL 需在原页面上下文存活时取出；data URL 解码后预算检查；短期签名 URL 转成本地字节，导入插件不再次拉取。跨域或认证资源无法获取时使用当前屏幕区域截图，不关闭 webSecurity、不无界抓取其他端口。

位图资源保持PNG/JPEG固化与内容哈希去重。m2.7的受限静态SVG以原生VECTOR和自包含svg字符串保存，不转PNG；内联页面样式冻结、本页use展开，外部SVG图片及背景复用尺寸/定位/裁切。源文件不支持的元素、引用或效果整体占位并告警，当前不执行早期草案中的栅格化回退。图片视口区分有/无viewBox，保留SVG自己的preserveAspectRatio；不能统一按位图拉伸。原生矢量映射、预算与用户范围见[docs/17](17-svg-and-icons-acceptance.md)。预览截图独立存放，不计入可编辑节点。

## 9. 绘制顺序与布局

m2.6当前子集已归一化常见position/z-index、opacity/isolation和Flex/Grid项的绘制顺序；普通非上下文祖先不再困住定位后代，适用的padding-box/圆角裁切通过原生Frame副本保留，绝对定位按包含块判断裁切祖先。必要时将上下文边框/选区背景分成原生SHAPE，保证背景/负层顺序。输出树按绘制关系组织，不保证等于DOM父级；坐标、内容、资源仍原生可编辑。复杂阶段/变换/隐式或单轴裁切明确告警，精确范围与LYR01–LYR07见[docs/16](16-stacking-and-clipping-acceptance.md)，不能将本批当作完整M2-07完成。

DOM 顺序不是最终绘制顺序。需要处理背景、负 z-index、定位元素、stacking context、透明度和 clipping。v1 用受控 fixture 验证常见情形，不能只按 zIndex 数字在全页面排序。

先输出视觉可对齐的原生绝对布局，再在检测到简单 Flex 且转换后几何偏差满足阈值时提供 Auto Layout。Auto Layout 是可选增强；失败就保留绝对布局并报告，不把整组栅格化。禁止自动把所有重复 div 认成组件。

输出命名优先 aria/role、语义标签、简短文字，其次功能启发式，最后类型+序号。保留源映射供诊断，避免把长 URL、令牌或个人信息放到图层名。

### 9.1 m2.9 常见外阴影

m2.9绘制补充：常见box-shadow读取完整计算列表（最多16层/长度绝对值≤10000px），受支持外阴影按CSS前到后保存。不透明底色、单个矩形盒、统一像素圆角的外观用独立原生SHAPE承载背景和DROP_SHADOW；父Frame保留整组透明度/内容，不将溢出子元素一起投影。背景层参与原有层叠归一化，自身overflow只裁内容，祖先有效裁切仍裁阴影。pruneScene按保守阴影外延保留仅阴影进入范围的节点，但不扩大内容clip或原选区。绝对定位生成框复用，原生渐变与底色一同移动。内阴影/透明底/复杂轮廓等明确告警，blur/spread边缘不声称Figma一致；完整范围与SHD验收见[docs/19](19-shadows-acceptance.md)。

## 10. 原型映射

支持的第一组交互是用户确认的 click→navigate、click→open overlay、click→close overlay。trigger 源可以是已导入元素，也可以是手工热点；目标必须在同包 screens 中存在。

两遍导入：先创建所有 screen 和节点，再解析动作目的地与写 reactions。缺少源节点或目标屏幕时跳过对应连线并报告，不随便连接到相似名称 Frame。

状态捕获是不可变快照，URL 相同也可以有多个状态。默认 instant 转场；Smart Animate、hover variants、滚动定位、变量条件和自动动作识别后续按实际需要增加。网页表单可输入、请求成功等行为不能被原样搬到普通 Figma 原型。

## 11. 预算与停止

起始预算：每捕获 5,000 个输出节点、单资源 10 MiB、全包 50 MiB、20 个 screen；实际超限前告知并提供缩小范围或分包。超过预算不得静默少导入一半。预算数值是待校准产品限制，不是上游 API 限制。

取消发生在阶段边界和批次检查点；捕获部分数据只能保留为 diagnostic，不自动标成完成。正常重试创建新 attemptId，同一次逻辑捕获可追踪前后尝试。

## desktop-1.0首版补齐（当前实现）

开放ShadowRoot/slot按composed树遍历、选择和祖先切换；assigned nodes只出现一次，不重复fallback。封闭组件不可读，空边界记missing，有光DOM内容时近似并告警；iframe/Canvas/video及filter等保留明确边界。最多500个运行中的CSS动画在采集前暂停并等待ready≤500ms，finally恢复原先运行的动画；不保证冻结任意网页JS/视频帧或全部动画。

PNG/JPEG继续固化，WebP/GIF先读受限头尺寸，再由无preload/Node/网络的隔离Chromium解码为PNG，8秒上限/取消关闭解码窗口，动画静态帧明确告警。资源最终仍通过PNG校验与原预算。

可选Auto Layout默认关闭，只把单行/列Flex、直接FRAME子节点、非负等间距/内边距与固定尺寸映射；换行、重叠、辅助层提升或不可靠几何保留绝对布局。项目保存不可变状态，手动配置navigate/open_overlay/close_overlay及原生透明热点，不录制源JS。详见[使用](20-desktop-release-guide.md)、[协议](04-data-and-bridge-protocol.md)和[验证](21-desktop-release-verification.md)。
