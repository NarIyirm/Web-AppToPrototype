# 13 全页采集与扩充长页验收

更新：2026-10-19。版本 m2.3 / Web DOM adapter 2 / 主包协议 1.0.0。本批全页与示例已获用户“这阶段我验证过了，没问题”的整体确认，M2-04 按本文范围完成，不补造 D01–D09 分项结果。以下操作清单保留供复现，后续按 HANDOFF 续接视觉还原。

2026-10-20 BUG-002修复补充：全页读取后的场景是不可变快照。滚动进度文字、时钟或后续新增内容只触发W_PAGE_CHANGED_AFTER_SNAPSHOT说明，不再因恢复滚动而误报E_LAYOUT_CHANGED。后续源参考一旦与快照内容不匹配即停止，已匹配参考保留；原生内容不扩展到读取后的新增区域。窗口尺寸/缩放/选择变化仍报E_LAYOUT_CHANGED，导航/取消/虚拟列表保护和旧成功包保留机制继续。无需重做本批已获确认范围。

## 1. 启动与入口

关闭旧桌面应用，在 `E:\WebToPrototype` 执行 `npm.cmd start`。点击“打开测试页”，默认示例现在是完整长页，仍保留原订单列表与按钮，后面增加计划、交接检查、懒加载图片、新增记录和页尾。

右侧“选择内容”→“采集范围”选择 **整个页面**。主操作仍在底部，不新增工具栏按钮；不需要先点选区块。

- 勾选 **滚动加载后转换**（默认）：逐段滚动触发加载，再读取已加载 DOM、生成分段源参考，恢复原位置。
- 取消勾选：不逐段滚动，只把当前已加载文档转为长画面；为统一 fixed/sticky 的静态位置，会临时到顶部，结束后恢复。屏外尚未触发的内容或图片可能仍是占位并附告警。
- 全页按当前浏览器宽度、文档顶部至实际采集高度生成一个 Frame。它忽略原有区块列表及排除项，不把列表清空；切回当前选区可继续使用。
- 未连接时可“预览转换”，连接插件后可“转换并发送到 Figma”。现有插件逻辑和主协议不变，仍须保持插件运行；桌面重启后重新配对。

## 2. 扩充后的本地例子

| 内容 | 用途 / 核对标记 |
|---|---|
| 原订单列表、PNG、详情弹窗 | 保留历史边框、中文、图片、正常浏览回归 |
| 顶部吸顶导航 | `STICKY_ONCE`，转换文字应只有一份 |
| 右下角固定帮助按钮 | `FIXED_ONCE`，转换文字应只有一份 |
| 项目概览、8 个计划阶段、6 条检查项 | `LONG_PAGE_MIDDLE`、`LONG_STAGE_1` 等，核对跨屏原生内容 |
| 4 张进入视口才设置图源的图片 | `LAZY_IMAGE_1` 至 `LAZY_IMAGE_4`，准备后文字显示“已加载” |
| 接近页尾后追加的 3 条记录 | `LAZY_APPEND_1` 至 `LAZY_APPEND_3`，真实新增 DOM |
| 页尾文字 | `LONG_PAGE_END`，核对是否到达追加后的新页尾 |

**比较两种方式前，请分别点击“打开测试页”重置文档。** 已经加载的内容不会因取消勾选而卸载；手工滚动也会触发加载，不能把已经展开的页面当作冷启动样本。

页尾还提供三个故障示例链接（正常浏览状态点击）：

- **列表回收示例** `/fixture-virtual`：6 个 row 节点随滚动复用，内容变化时拒绝宣称完整全页。
- **无限加载示例** `/fixture-infinite`：接近底部不断追加，达到预算后停止、标注部分范围。
- **超高页面示例** `/fixture-tall`：约 42,000px，验证 30,000px 上限与裁切。

每个故障页顶部有“返回长页测试”；也可直接点应用的“打开测试页”。这些页面由当前实例本机服务提供，不依赖外部站点或远程图片。

## 3. 全页边界与恢复

1. 高度最多 **30,000 CSS px**，准备最多 **30 次滚动 / 30 秒**，整个转换另有 90 秒等待预算；页面单次读取/截帧有 15 秒保护。上限不是无限页面已完整获取的保证。
2. 达到高度、步数或时长上限时，只输出本次已覆盖的有界范围。结果摘要和 `W_FULL_PAGE_PARTIAL` 说明实际高度与原因，不以“完成”暗示全站所有内容已加载。
3. 沿用单 screen 3000 元素/5000 图层/60000 字符等提取预算，以及包/图片预算；全页模式不会无限放大内存和图片限制。太复杂时明确报错，可改用区块/多选。
4. 从顶部快照读取一次 DOM。fixed 元素采用顶部视口中的位置一次，sticky 元素采用顶部滚动状态的位置一次，保留静态可编辑外观；不恢复原生网页中的吸顶/固定交互。
5. 处理中显示阶段/局部进度，支持 **取消采集**。取消或失败保留上次成功转换；结束后恢复原滚动位置并解除页面选择锁。源网页内 Esc 也可请求中止准备，但读取/绘制中的取消可能需要等待当前受控步骤结束。
6. 如果页面导航，旧采集立即终止；不把旧滚动位置套到新文档。页面退出或异步读取未返回也有中断/超时保护。
7. 滚动准备会触发网页本身的加载逻辑，已经追加的 DOM 或发出的网页请求不会被“撤销”。恢复指浏览位置和工具状态，不承诺回滚远程业务变化。
8. 列表回收检测是启发式：记录可见列表项的节点/文字，发现移除或替换时保守拒绝。本批不能识别所有虚拟化框架，也不能把内层独立滚动容器的所有行自动展开；复杂情况使用视口/分段区块采集。

## 4. 分段源参考与保存

长页源参考最多 12 段、总位图约 32 MiB；每段沿用最长边 2048px 的预览限制。短长页按连续位置取图（底部可能有重叠），超过段数时均匀抽样并标注，不伪称拼接的完整长截图。

结果页“源参考位置”可以切换各段，文字说明当前 y、分段/抽样状态。**真实网页的 fixed/sticky 元素可能在多张源参考里重复出现，导出的原生节点仍各一份。** 源参考是排版对照，不能代替 Figma 中的图层数量与可编辑性验收。

保存主 JSON 与附件示例：

```text
page.json
page.json.preview.png
page.json.preview.json
page.json.screen-1.segment-2.preview.png
page.json.screen-1.segment-2.preview.json
...
```

首段保留旧附件命名，后续元信息记录 segmentIndex/segmentCount/referenceMode、screenId、包版本、原文档坐标和 SHA-256。重开逐段校验，后续损坏/错配段跳过并提示，其他有效段仍可查看；首段保存段数索引，若它缺失或损坏，该画面参考不加载，主包仍能导入。任意导入的 screenId 不会直接解释成文件路径；非标准 ID 使用稳定摘要后缀。Figma 仍只需主 JSON，源参考不进入图层 assets，也不通过桥接作为整页大图导入。

## 5. 用户验收清单

| 编号 | 操作 | 预期 |
|---|---|---|
| D01 正常全页 | 重置测试页，在中间停留；选整个页面并启用滚动准备，预览后发送 | 完成后回到原位置；Figma 是一个长 Frame；能找到并编辑 `LONG_PAGE_END`、`LAZY_APPEND_3`、中段与计划文字 |
| D02 图片与固定层 | 检查上述 Figma 画面 | 4 张懒加载图和原订单 PNG 存在；`FIXED_ONCE`、`STICKY_ONCE` 各一份；它们是静态外观 |
| D03 已加载模式 | 重新打开测试页，取消滚动准备后转换 | 只保留当时文档已有内容；下方未加载图可占位告警，不承诺出现 `LAZY_APPEND_3`；恢复原位置 |
| D04 取消与保留 | 保留一个成功转换，重新采集时点取消 | 显示取消，回到原位置，仍可正常滚动浏览；上次结果仍能发送/保存，没有半包覆盖 |
| D05 无限加载 | 打开无限加载示例，启用准备 | 有界停止，摘要明确部分范围和原因；不是卡死或无限等待；恢复原位置 |
| D06 回收列表 | 打开列表回收示例，启用准备 | `E_FULL_PAGE_VIRTUALIZED` 明确拒绝；旧成功包保留，可转用视口/区块 |
| D07 超高页面 | 打开超高示例，关闭准备后转换 | 根 Frame 高 30000px，含 `HEIGHT_INSIDE`，不含 `HEIGHT_OUTSIDE` 原生文本；有部分范围提示 |
| D08 分段重开 | 切换源参考，保存整包，重开 | 各段位置和图像可核对，源附件不成为 Figma 整页截图图层；缺附件只影响参考 |
| D09 原流程回归 | 在扩充页选择原订单 Section、矩形或多选，并正常打开详情按钮 | 已接受的选择、排除、边框与正常网页操作仍可用 |

反馈格式：`D01：通过/失败；准备开关；原滚动位置是否恢复；缺失标记；Figma 根数量；错误原文；JSON/报告/截图路径`。不要求分享配对秘密。所有最终真实 Figma 结果由用户提供，本批开发不会代替操作真实文件。

## 6. 开发检查与实现资料

新增 `npm.cmd run smoke:full-page`，使用真实 Electron、真实本地页面、真实 IPC/资源/磁盘；原生文件选择器仅在测试中提供固定路径。旧 Section/矩形/多选及桥接脚本继续回归；桥接的画布宿主为模拟，不冒充真实 Figma 导入。

源代码为 full-page.ts 协调预算与恢复、capture.ts 提取/来源检测、main.ts 取消/导航保护与截图时序、preview.ts/preview-path.ts 附件。全页在后台期间临时关闭该 WebContents 的计时节流，完成后恢复；使用受控真实绘制让 IntersectionObserver 先触发并稳定，再冻结布局读取，不放松 Node/IPC/网络隔离。

实现时核对 [Electron 截帧与后台节流](https://www.electronjs.org/docs/latest/api/web-contents/) 和 [Window.scrollTo](https://developer.mozilla.org/en-US/docs/Web/API/Window/scrollTo)。最新实际结果与证据见 [PROGRESS](PROGRESS.md)。
