# 手机网页采集与电脑原型操作

2026-10-21。对应用户授权的第一、第二项：补齐手机网页采集，完善电脑结果检查与原型操作。Android/iOS 使用同一套产品流程；手机与真实 Figma 最终验证由用户执行。未触发手机构建或发布。

## 已实现

- 手机网页工具增加父级、多选、排除、撤销、清空；保留浏览、元素和双向矩形。多选按相对位置合并为一个画面，排除项不生成图层，参考图保留原网页并明确说明。选择覆盖层不会进入截图；导航、滚动或尺寸变化使旧选择失效。
- 保存长页从顶部逐段滚动，合成一个画面；每段确认实际滚动位置，末段重叠不重复拼接。固定内容与已出现的吸顶内容后续隐藏，完成、取消或失败后恢复样式和原滚动位置。上限 12,000 CSS px、20 段、45 秒采集循环；单次读取超时 8 秒，编码/保存可能额外耗时。达到上限保存已采集部分并说明；取消不保存新画面。
- 长页逻辑尺寸独立于参考图尺寸，图片仍不超过 4096 边长、10 MiB。文字被段边界切开时保留像素，避免漏掉文字后半部分；整段图层总数保留根节点预算。
- 网页观察补充字体族、字重、行高、对齐；读取常见纯色背景和图片区域。渐变、阴影、变换、透明叠层、表单、跨域内容等保留像素；裁切文字保留图片，基础祖先滚动裁切生效。没有把任意 CSS 宣称为完整支持。
- 电脑可切换源画面/转换预览，按文字、形状、图片或缺失筛选、定位图层；显示当前画面的内容数量，合并重复提醒。转换预览为浏览器示意，字体、字距、复杂效果仍以 Figma 实际结果为准。
- 加入原型可选择当前画面或整批画面。项目显示缩略列表，并按“选画面 → 选点击区域 → 设动作”组织；支持源参考/转换画面、放大、热点绘制与已有连线定位。删除生成热点的连线时清理该热点。
- 本地试播只使用已保存连线，支持跳转、打开/关闭弹窗；小画面也可使用文字动作按钮试播。生成项目后返回转换结果，再发送 Figma。

## 最短验证

1. 关闭旧电脑端，在 `E:\WebToPrototype` 运行 `npm start`。手机刷新当前 SDK57 Expo Go 项目；没有新增原生依赖，不需要为这批功能先构建安装包。
2. 手机添加画面 → 打开自有测试网页。选一个标题，点“选父级”；开启多选再选另一块。选“排除”点块内内容，检查选框与计数，试一次撤销。工具条可左右滑动。
3. 保存所选范围，扫码发到电脑。电脑手机素材 → 转换并打开。切换源画面/转换预览；筛选文字与图片，检查排除项不会生成图层。
4. 手机返回网页，滚动到中间后点“保存长页”。确认保存为单个长画面，返回网页恢复原位置。另试一次取消；已有画面应保留，新画面不应增加。
5. 发送两个不同画面到电脑，在转换结果选择当前/全部加入原型。选择画面，拖热点并设置目标，保存连线。试播跳转，再试打开/关闭弹窗。
6. 生成原型项目并发送 Figma，检查实际图层编辑与原型播放。反馈最后成功步骤、问题画面和提示即可。

## 边界与开发证据

不自动滚动内嵌滚动区，不保证虚拟列表、持续变化内容、跨域内部结构、任意层叠/复杂样式完整重建。长页图像可能缩小；布局文字保留逻辑坐标，低分辨率参考中的图片细节仍有限。浏览器示意不会证明真实 Figma 的字体或弹窗行为。

开发检查记录在 `.runtime/2026-10-21-check.log`、`.runtime/web-workflow-check.json` 与移动 `docs/verification/latest-check.json`。只在隐藏独立 Electron 实例使用合成页面检查选择脚本和结果/项目流程；未操作用户网页、手机或 Figma。

API 核对：[SDK57 WebView](https://docs.expo.dev/versions/v57.0.0/sdk/webview/)、[SDK57 ImageManipulator](https://docs.expo.dev/versions/v57.0.0/sdk/imagemanipulator/)、[view-shot 官方说明](https://github.com/gre/react-native-view-shot/blob/master/README.md)。使用现有依赖与已装类型，保留 SDK57、app.json、EAS 与暂存内容。
