# Windows首版使用与最终验收

版本：0.1.1，2026-10-21。新增手机截图的可靠文字、平色背景与基础控件拆层，其余内容保留局部图片；网页采集继续沿用原通路。开发检查与最终设备验收分开记录，不宣称任意网站或所有 CSS 完整还原。移动端 1.0.1 与本版配套，自动探索和自动推断业务逻辑属于后续。

## 运行分发包

解压整个Windows分发ZIP，双击 `WebToPrototype.exe`。保留同目录DLL、resources和locales，不需要安装Node、npm或启动开发服务器。可选运行 `Install.cmd` 复制到当前用户应用目录并创建开始菜单快捷方式，无需管理员权限。应用和Electron运行时未做代码签名。

Figma桌面版 → Plugins → Development → Import plugin from manifest，选择分发目录 `FigmaPlugin/manifest.json`。运行插件并保持打开；桌面生成配对码，在插件粘贴连接。沿用原插件ID，新版请关闭重开原插件。插件不需要访问公网服务。若本机43821端口已被其他程序占用，应用会提示；关闭冲突程序后重试。

数据目录可在“诊断与文件工具”查看。开发运行和分发版可能使用不同的用户目录；迁移请先“备份项目”，再在新版“打开项目副本”。升级前保留旧分发目录和导出包，避免覆盖正在运行的版本。

## 网页转换

地址栏支持本地HTTP和公网HTTPS，网页需要登录时在内置浏览器操作。会话独立，不读取外部Chrome资料。选择元素/区块、视口、整个页面或矩形；连续多选、排除和独立/合并输出保留。全页仍有高度、步数和时间上限，结果会说明部分范围。

点击“预览转换”检查源参考和告警，再发送或保存。源参考是网页截图，不能当作导入结果。保存对话框可以选JSON或ZIP；插件和桌面都可读取。ZIP内有capture.json与图片，离开源页面仍可导入，源预览侧文件仅供对照。不要只拷贝预览附件而遗漏转换包。

全页中的滚动进度、时钟等可能继续更新。新版保留读取时的可编辑快照，并以W_PAGE_CHANGED_AFTER_SNAPSHOT提示；不再将恢复滚动造成的普通更新当成失败。不匹配的后续分段参考会停止生成。采集中请保持窗口尺寸和缩放不变；如需最新页面内容，可再次采集。

PNG/JPEG原样固化，WebP/GIF通过隔离Chromium解码固化为PNG；动画只保留解码时静态帧。图片仍限单边4096px、单资源10MiB和既有整包预算。普通开放ShadowRoot与slot按实际显示子树采集，封闭组件内部不可读取。嵌套虚拟列表、复杂变换/滤镜/蒙版、内阴影和特殊SVG等继续明确告警，不自动把整页转截图。

“捕获历史与浏览器设置”可重开最近20次转换，缓存上限256MiB。可指定320–2560宽、240–3000高的CSS视口，画面缩放以适配工作区；原生滚动条不转换为图层，实际内容宽度可能略小于视口宽度。恢复“随窗口调整”可回到默认。清除会话需在原生对话框确认，只清除本应用网页登录/缓存，不删除项目与导出文件。

## 多状态与原型

1. 在网页准备第一个状态并转换，展开“项目与原型”，点击“当前转换保存为状态”。
2. 回到网页正常操作，进入详情、切Tab或打开弹窗，再转换并保存。URL相同也保留为独立状态，最多20个状态，整包仍受节点/资源预算约束。
3. 可以重命名、排序和删除状态。删除会同时移除相关入站/出站连线；不会改源页面。项目在本地自动保存。
4. 选源状态，用元素列表或参考图点选触发元素；也可在热点模式拖矩形，或填写相对于画面的CSS坐标。
5. 选择“跳转到状态”“打开弹窗状态”或“关闭弹窗”，保存连线。同一元素只有一个点击动作，再次设置会替换。关闭动作无需目标。
6. 点击“生成项目”，再使用原有结果区发送/保存。Figma导入时创建所有状态，再建立原生跳转/Overlay连线。不会录制网页JS、表单提交或后台业务。

弹窗建议单独选择dialog/弹窗容器作为状态，便于Figma Overlay演示。整页包含顶层弹窗/浏览器backdrop的复杂绘制仍会告警。

“备份项目”保存可继续编辑的w2p-project.json，包含状态、预览和连线；与仅用于导入的capture JSON/ZIP不同。“打开项目副本”保留原状态ID和连线并创建新项目标识，先备份当前项目。新建项目也会先备份。异常项目不会当作空项目静默覆盖；原文件保留，可从备份恢复。

可选Auto Layout默认关闭。开启后只将可靠的单行/单列Flex、稳定间隔和固定子尺寸映射成原生布局；有换行、重叠、提升辅助层或不可靠几何时仍保留绝对布局。不会强制重排复杂页面。

## 本地完整验收

从长页页尾打开“完整原型流程”（/fixture-prototype），准备“列表”“详情”“确认弹窗”三个状态。设置列表→详情、详情→打开弹窗、弹窗→关闭、详情→返回列表；可加一个矩形热点。生成项目发送到Figma后播放，确认所有触发区、目标与关闭/返回正确，再编辑文字、图片及一个原生效果。

/fixture-auth可验证本地手动登录和受会话保护的图片；不带Cookie的接口返回401。开发自动检查不等同用户真实账户或全部公网兼容证明。本轮用户指定只用本地验证，没有访问用户生产系统。

## 恢复与限制

连接断开时保留转换包，可继续文件导入。队列最多5个任务、待发数据合计100MiB，每个包仍限50MiB；原生导入按序执行。分块传输逐块与整包校验，目标页面变化会阻止继续。未确认的导入不会在应用重启后自动重建，先核对Figma已有结果；不要用重发来掩盖不确定状态。

日志位于数据目录logs，单个约1MiB，保留3份；只记任务标识/计数和错误码，不记录配对码、会话令牌或页面正文。历史20条/256MiB、项目含预览128MiB；超限会拒绝新写入或按历史策略清理旧缓存，已导出的文件不受影响。请使用项目备份长期保存重要内容。

ZIP仅接收有界Store/Deflate、CRC与资源校验通过的自包含包，不支持ZIP64、加密、多卷或任意附件。旧插件不能读取auto-layout能力时需重载新构建，不降低预检绕过。

更多现有视觉边界见docs/14–19。字体替代可报告，逐字缺字与不同引擎模糊边缘仍需真实Figma检查。分发包签名、商店发布和Android不在本次首版范围。

## 开发命令

`npm.cmd run check`、`npm.cmd run smoke:workflow`、`npm.cmd run smoke:stress`、`npm.cmd run smoke:bridge`、既有专项smoke，以及`npm.cmd run package:windows`。打包产物写到release内新时间戳目录，不删除或覆盖旧基线；SHA256清单供完整性核对，不是代码签名。具体实际结果见PROGRESS和发布检查记录。

## 卸载与回退

关闭程序后，可删除便携目录；通过Install.cmd安装的版本可删除当前用户应用目录中对应的版本文件夹与开始菜单WebToPrototype快捷方式。项目数据目录默认保留，先备份再决定是否清理。回退时运行旧分发目录，导入已备份项目副本，不覆盖Figma中已编辑的画面。
