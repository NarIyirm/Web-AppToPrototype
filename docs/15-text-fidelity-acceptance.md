## 入口与运行

1. 在 `E:\WebToPrototype` 运行 `npm.cmd start`，重启以载入 m2.5 采集器。
2. Figma 中关闭并重新运行原本的开发插件，加载最新构建代码；无需换插件 ID。桌面重启后重新配对。
3. 点击“测试页”，原长页页尾进入“富文本与字体基准”；应用运行时也可直接访问 [本地文字页](http://127.0.0.1:43821/fixture-text)。旧视觉页及故障页保留。
4. 使用区块、整个页面、矩形或多选按日常方式转换/发送。文字页没有懒加载，可关闭全页滚动准备。新包 producer.converterVersion 为 `m2.5`，包含新文字字段时声明 `styled-text`。

旧保存包继续可导入，但不会重新计算富文本；检查本批请重新采集。源参考仍是网页截图，不是 Figma 输出结果。

## 当前实现与边界

- 从 DOM Text 节点和 Range 读取渲染文字，不用祖先 innerText 反复生成文本。按完整字素读取，索引与 Figma 一样采用 UTF-16。
- 合并条件：同一个输出文字容器、同一视觉行、相邻且无明显间隙/重叠，字号、行高和字距一致；只跨透明、静态、基线一致且无背景/边框/内外边距/裁切/特效影响的行内祖先。合并保留颜色、字体、字距和单一装饰线。
- 行内背景、透明度、atomic/定位元素等保持自己的原生父子片段，不为减少图层数改变绘制顺序；混合字号/基线暂不统一为一个文本层。
- 一行一个可编辑 Text 是保留位置的当前策略。居中/靠右按实际行的坐标保存，Text 本身是左对齐的行片段；它不等同于拥有整段重排能力的原生段落。编辑长度可能需要手工调框。
- upper/lowercase 支持常见语言映射并更新输出样式范围。capitalize/full-width、RTL/竖排、两端对齐、制表符、文字阴影、特殊字形和可变字体特性等输出 W_TEXT_LAYOUT_UNSUPPORTED，保留可编辑近似。
- 下划线/删除线采用 Figma 默认装饰。自定义颜色/粗细/波浪/多重装饰等输出 W_TEXT_DECORATION_APPROXIMATED，不保证与CSS的每个参数一致。
- 字体列表、字重与斜体解析已改进，导入前加载实际字体。缺字与字体替代不是同一件事：本批只诊断可用字体/替代，对emoji提供 I_TEXT_GLYPH_COVERAGE_UNVERIFIED；没有可靠的逐字缺字检测，不自动下载或安装字体。
- 节点、元素、文字和整包预算不放宽；全页/选择/取消/恢复逻辑不变。未增加多状态或原型交互、Auto Layout、Android或安装包。
