# 当前视口、自由框选与源预览验收

版本：converterVersion=m2.1 / adapterVersion=web-dom-2，2026-10-19。

当前交付：保留已通过的元素/Section 采集，新增当前视口、严格矩形、完整元素吸附、源截图预览及保存重开。开发检查与最终用户验收分别记录；最终 Figma 效果由用户测试。本轮没有开发全页、多选/排除或自动交互。

## 1. 启动

关闭旧 WebToPrototype 窗口，再运行：

```powershell
Set-Location -LiteralPath 'E:\WebToPrototype'
npm.cmd start
```

现有 Figma 开发插件 **WebToPrototype · M0 验证** 可直接导入新包，协议未变，无需重新安装。若旧插件面板还开着，关闭后重新运行即可。测试时建议在空白 Page 上导入新副本，与旧结果对照。

界面新增：“自由框选”“转换当前视口”、右侧“框选边界策略”和“源截图对照”。

## 2. 推荐先测试的六个场景

| 编号 | 操作 | 通过标准 |
|---|---|---|
| U01 当前视口 | 打开本地测试页，不选 Section，直接点击“转换当前视口”，保存主 JSON 并导入 Figma | 只包含当前可见范围，根 Frame 为该范围的 CSS px 尺寸；原生浏览器滚动条不作为图层；文字和基础形状仍可编辑 |
| U02 严格框选 | 右侧选“严格按框裁切”，点“自由框选”，在网页拖出矩形，让边界穿过文字或按钮，再点“转换选中区块” | 根 Frame 与拖出的矩形尺寸一致；边界之外内容被根 Frame 裁切，不把文字转成截图或删除文字后半段；源预览与框内区域一致 |
| U03 包含完整元素 | 右侧改为“包含完整元素”，重新框选按钮内部的一小块，再转换 | 实际采集边界扩展到完整按钮，预览说明同时显示原框和实际尺寸；Figma 中按钮完整、可编辑，不误扩展成整个 body |
| U04 源预览与重开 | 保存转换包；确认同目录有两个预览附件；关闭并重启应用，再“重开转换包” | 画面名称、尺寸、模式、源截图和告警恢复；截图不出现在 Figma 图层或 assets 图片计数里 |
| U05 滚动与取消 | 滚动到页面其他位置再转换视口；进入自由框选后按 Esc；反向拖拽；拖出小于 4px 的框 | 视口内容与滚动后页面一致；Esc 退出且不误触网页按钮；反向拖拽尺寸仍为正；太小的框提示重画，不生成零尺寸包 |
| U06 旧功能回归 | 用元素/Section 采集订单区块并导入 Figma | 中英文、图片、按钮和订单底部分隔线仍正常，BUG-001 不复发 |

U02 中可在 Figma 图层面板选中文本检查完整内容，或暂时关闭根 Frame 的 **Clip content** 查看保留的框外内容，检查后恢复裁切。保留框外的完整文本是为了编辑，不代表采集范围不生效。

U03 的“完整元素”当前针对相交的按钮、链接、图片、文字块、简单行容器和叶子元素做一次扩展；保留网页自身的 overflow 裁切。它不是任意复杂组件的语义识别器，也不会扩展后继续吸附相邻元素。若吸附范围超过四个视口宽/高，会要求缩小范围或改选 Section。

## 3. 保存文件说明

若主文件保存为 `orders.json`，同目录会有：

| 文件 | 用途 |
|---|---|
| orders.json | 自包含可编辑场景；在 Figma 插件选择此文件 |
| orders.json.preview.png | 源网页截图，用于人工对照 |
| orders.json.preview.json | 截图与 packageId/revision、采集范围、尺寸、摘要的关联信息 |

源预览是截图，不是“转换结果已经达到同样效果”的证明；需要与 Figma 结果对照。它不计入可编辑图层或普通图片资源数，也不会嵌入主 JSON 作为整页替代。

日常留存建议保留三个文件在一起；仅发送主 JSON 也可以正常导入 Figma。改名时两个预览附件也需保持命名关联。预览不匹配、损坏或缺失时，应用会提示没有匹配预览，不能拿上一份截图代替。

截图最长边缩至 2048px，仅影响对照清晰度，不改变原生图层 CSS 尺寸。若元素/完整元素边界超出当前视口，预览只包含其可见部分，界面会明确提示“仅覆盖选区当前可见部分”；没有自动滚动拼接截图。

采集结果是某一时刻的快照。之后滚动、选择其他内容不会自动改写已生成的包。页面在采集中途滚动、改选或改变视口时，应提示 `E_LAYOUT_CHANGED` 或 `E_TARGET_CHANGED`，重新采集即可。

2026-10-20 BUG-002补充：以上滚动限制针对选区/视口。全页会主动滚动并恢复原位置，快照读取后普通文字/内容更新不会丢弃已读取结果；停止生成不匹配的后续参考并提示W_PAGE_CHANGED_AFTER_SNAPSHOT。真实导航、取消、视口/缩放变化仍中止采集。

## 4. 可选边界检查

- 在同一原始矩形上切换边界策略，再点转换。策略生效在下一次转换，旧预览保持原包，不自动重算。
- 框选后改变桌面窗口大小。矩形选择应失效，重新拖选；元素选择仍按新的实际布局读取。
- 普通浏览操作中点击网页按钮应正常；自由框选期间拖拽经过按钮应只框选、不触发业务操作。
- 若方便，在页面缩放后重试，比较 CSS px 尺寸和截图；开发检查覆盖过 125%，最终以你常用环境为准。应用暂未新增缩放控制按钮。
- 复制主 JSON 到其他目录，不复制附件，再重开。预览应明确缺失，主包仍可正常导入 Figma。
- 对包含 fixed/sticky 的自己的页面采集视口。它保留本次视口位置；复杂层叠/transform 等仍可能告警，未宣称完整兼容。
