## 本地测试

Expo Go 地址为 `exp://192.168.1.101:8082`，二维码保存在根 `.runtime/expo-go-local-test-8082.png`。这是本轮启动地址，电脑网络变化后需要重新取得。8081 上的已有服务没有停止。

电脑已构建并启动本地新版，使用独立测试目录 `.runtime/local-user-test-2026-10-21`，旧安装包正常退出，原项目数据没有修改。若需重新启动，在项目根目录运行 `npm start`；手机项目目录运行 `npm run start:go -- --port 8082 --offline`。不要同时打开旧安装包占用连接端口。

1. 用 Expo Go 打开本轮本地项目。进入“添加画面 → 转换 App 画面”，选择“从相册导入 App 截图”，或用内置示例生成截图。
2. 预览/裁切后发送到电脑；若连接已失效，在新版电脑窗口生成新手机配对码并重新连接。
3. 电脑“手机素材 → 转换并打开”，查看结果，再通过现有 Figma 插件导入。插件仍兼容已有 Text/Shape/Image 协议；若桥接断开，重新配对。
4. 在 Figma 双击文字并修改内容；选择背景或纯色控件修改填充。照片、图标和复杂图案会保留为局部图片。检查是否有漏字、文字重复、明显错位和内容缺失。

原 App 的组件树、字体文件及业务逻辑无法从普通截图直接取得；本轮是文字和基础几何重建，不承诺恢复原始组件或所有矢量。

## 采集按钮

iOS ReplayKit 控件原先用零尺寸初始化，再靠外层视图更新；现改为实际 64 点初始化和布局、明确颜色与操作说明，并提供控制中心长按录屏选择“界面采集”的备用指引。JS 控件布局、启动/停止说明与展开帮助已在实际组件的 React Native Web 渲染中验证，系统控件用测试占位替代。

Expo Go 不包含本项目自定义 ReplayKit 模块，不能验证真实跨 App 广播或这次 Swift 修复。其页面明确显示此限制，可先测试截图导入、预览、发送和拆层。用户确认本地结果后，才准备下一轮独立安装包真机检查。
