## 1. 推进顺序

M0 外部可行性 → M1 最小真实闭环 → M2 选择与视觉能力 → M3 稳定性与桥接 → M4 基础交互 → M5 用户验收与分发。

优先打通最薄链路，不先完成复杂 UI 再发现 Figma 端不可用。M0/M1 使用人工样例和本地 fixture，不需要先获取 Android 手机或用户生产系统权限。

以下“工作量”是单人实现的相对尺度：S 通常半天内，M 通常 1–2 个工程日，L 通常 3–5 个工程日，XL 必须拆分后估算。它不是交付日期承诺；Figma 环境验证、字体与复杂布局会改变实际成本。
