# 桌面右侧工作台

2026-10-20。用户要求连接集中在上方、其余内容按使用逻辑组织，保留简约风格。用户已自行解决之前的包校验问题，本次不调整转换协议。

- **设备连接**：右侧最上方常驻 Figma、手机状态。点击对应按钮展开配对，另一项详情收起。Figma 详情提供配对码与插件路径；手机详情提供二维码、网络地址及关闭接收。
- **网页采集**：选择范围、管理区块，底部预览转换或转换并发送。
- **手机素材**：接收画面自动刷新并显示数量；选择收件，底部转换并打开。没有素材时可直接进入手机连接。
- **转换结果**：检查源画面、名称、告警，保存文件或加入原型项目；底部发送到 Figma。
- **项目原型**：管理状态、排序和点击连线；底部生成原型项目，再到转换结果发送。加入画面后自动进入本页。

历史、浏览器设置及诊断位于下方折叠区。页签支持方向键、Home/End；切换任务回到内容顶部。连接状态和主操作不会随长表单滚出视野。面板宽度、网页视图边界及原有数据保持。

使用：关闭旧桌面进程，在 `E:\WebToPrototype` 运行 `npm start`。先体验顶部连接入口，再切换四个页签确认按钮语义与当前任务一致；手机流程为“顶部手机 → 生成手机配对码 → 手机发送 → 手机素材 → 转换并打开 → 转换结果”。真实手机配对、Figma 导入和原型播放由用户反馈结果。

开发检查：TypeScript、桌面/插件编译通过；隐藏独立实例的四页签、对应底部操作、连接展开及最小窗口无横向溢出检查通过，无渲染错误。没有运行手机云构建、创建 Apple 项目、提交或推送。
