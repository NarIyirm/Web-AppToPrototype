## 当前支持边界

- 图片：已固化 PNG/JPEG；五种 object-fit；浏览器规范化后的常见百分比、px、关键字及 `calc(百分比 ± px)` 定位。按 CSS 内容区裁切，保留外框、内边距、底色。`none` 使用网页 density-corrected naturalWidth/Height。
- 背景：单个 url，cover/contain/auto、常见 px/% 尺寸与定位，border/padding/content-box 的 origin/clip。非重复绘制；默认 repeat 只有在单图已覆盖重复轴的整个裁切范围时可沿用单图，否则告警省略。round/space、多背景、固定/局部附着、blend、text clip 暂不还原。
- 渐变：单层非重复 linear-gradient；deg/turn/rad/grad、边/角方向；2–32 色标；百分比、px、自动分配、双位置色标和重复位置硬边；sRGB 颜色及 alpha。角方向按矩形比例处理。
- 不支持的径向/conic/repeating 渐变、多层混合、插值提示、显式色彩插值空间/现代广色域色标、超出 0–100% 的色标、自定义渐变背景尺寸/定位会明确告警。保留底色与原生内容，不静默整页栅格化。
- 复杂 transform、层叠、滤镜、椭圆/百分比圆角仍是既有限制；普通圆角与内部裁切保持原生。图片、节点、资源和全页预算及取消/恢复机制不放宽。
